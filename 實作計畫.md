
## 3. Batch KSF-B：Full Index Builder

### 實作順序

```text
1. 建立 full index builder。
2. 實作 deterministic topic key。
3. 實作 aliases builder。
4. 實作 keywords builder。
5. 實作 learning stage inference。
6. 實作 retrieved_sources builder。
7. 寫出 knowledge-full-index.json。
```

### Spec

新增 script：

```text
scripts/runtime-index/build-k12-full-runtime-index.mjs
```

輸入：

```text
datasets/K12-KGraph-HF/K12-KGraph/subject_specific_KG/*.json
```

輸出：

```text
storage/knowledge/index/knowledge-full-index.json
storage/knowledge/reports/k12-full-runtime-index-report.json
```

Topic key 規則：

```text
k12_demo_<source_node_id>

example:
k12_demo_math_7a_rjb_cpt41
```

Learning stage 推論：

```text
1a-6b  -> elementary
7a-9b  -> junior_high
bx*    -> senior_high
xzxbx* -> senior_high
unknown pattern -> unknown
```

Aliases 規則：

```text
必含：
- node.id
- node.name
- topic_key
- properties.aliases[]

數學一元一次方程 demo-critical alias 額外補：
- 一元一次方程
- 一元一次方程式
- 一次方程
- 一次方程式
- linear equation
- linear equation in one unknown
- one-variable linear equation
```

Keywords 規則：

```text
從以下欄位抽取：
- name
- properties.definition
- properties.description
- properties.examples[]
- properties.formula
- connected section/chapter names

需去重、去空白、限制長度，避免整段教材原文塞進 keywords。
```

Retrieved source 規則：

```text
每個 runtime topic 對應一個 k12_dataset source ref。
metadata 補：
- node_label
- node_properties
- subject
- adjacent_edges_summary
- appears_in section/chapter/book
- license_scope=non_commercial_demo_only
- official_curriculum_verified=false
```

### 如何做

```text
1. 用 Node.js fs/promises 讀取四科 JSON。
2. 建立 nodeById 與 inbound/outbound edges index。
3. 每個 node 都先轉成一個 topic。
4. 對 Exercise topic，topic_label 優先用 stem 或 name。
5. 對 Book / Chapter / Section topic，標成 structural topic。
6. 對 Concept / Skill / Experiment topic，標成 teachable topic。
7. retrieved_sources[].description 對應 definition / description / stem / name。
8. 所有輸出排序固定，確保 checksum deterministic。
```

### 驗收門檻

```text
1. builder 成功產生 knowledge-full-index.json。
2. topics.length 約等於四科 nodes 總數，允許因 policy 過濾而略小。
3. topic_key 不重複。
4. aliases 內不含空字串。
5. retrieved_sources 每個 topic 至少 1 筆。
6. math_7a_rjb_cpt41 被轉成 topic。
7. `一元一次方程式` 可以 resolve 到 k12_demo_math_7a_rjb_cpt41 或同族 topic。
```

## 7. 實作注意事項

### License / Claim

```text
K12-KGraph-HF / K12-Dataset 只能作為 demo / non-commercial source。
knowledge-full-index.json 不可宣稱台灣官方課綱 verified。
所有 topic metadata 都應標示 official_curriculum_verified=false。
```

### Performance

```text
四科總節點約 10685，總邊約 22471。
完整 index 可以作為 local JSON artifact，但 API response 可能變大。
短期 demo 可接受；後續 mvp/prod 需考慮 pagination、topic query API 或 compressed artifact。
```

### Data Quality

```text
原始資料為簡體中文與人教版教材脈絡。
Demo 可以使用，但不可當作台灣正式教材或課綱。
alias 需要補繁體常用詞，否則 zh-TW prompt 仍可能 miss。
```

### Compatibility

```text
不要直接覆蓋現有 9-topic knowledge-index.json。
先新增 knowledge-full-index.json。
再由 demo profile alias 指向 full index。
這樣不會破壞現有 Batch E-J regression baseline。
```
